# Nadie Me Preguntó

App de noticias de la comunidad Nadie Me Preguntó: reportes de pre-mercado y post-mercado, agenda económica y educación financiera sobre bolsa y cripto.

**Informar, no decidir.** Todo el contenido es educativo e informativo; no es asesoramiento financiero ni recomendación de compra o venta.

- `index.html`: la app (sin dependencias, funciona en GitHub Pages).
- `data/feed.json`: los reportes y datos que muestra la app. Para publicar un reporte nuevo, se agrega al arreglo `reports`.
